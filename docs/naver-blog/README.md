# 네이버 블로그 이미지

블로그를 꾸밀 때 쓰는 네 장이다. 유령 심볼은 `app/icon.svg`, 워드마크는 `app/Logo.tsx` 의 규격을 그대로 쓴다.

배색은 사이트 화면과 같다(`app/styles/theme.css` 의 라이트 토큰). 옅은 바탕 · 흰 카드 · 잉크 글자에 파랑은 유령과 말풍선 하나에만 쓴다. 첫 판은 네 장 모두 로고 파랑을 바탕에 깔았다가 너무 파래서 촌스럽다는 말을 듣고 걷어 냈다(2026-09-30). 다크 모드 배색으로 된 어두운 판도 뽑을 수 있다(아래 '다시 그리기').

| 파일 | 올리는 곳 | 크기 |
|---|---|---|
| `profile-512.png` | 관리 > 기본 설정 > 블로그 정보 > 프로필 이미지 | 512×512 |
| `mobile-cover-1080x1300.png` | 블로그 앱 > 내 블로그 > 홈 편집 > 커버 이미지 | 1080×1300 |
| `pc-title-966x300.png` | 관리 > 꾸미기 설정 > 세부 디자인 설정 > 타이틀 > 직접 등록 | 966×300 |
| `widget-170x600@2x.png` | 관리 > 꾸미기 설정 > 레이아웃·위젯 설정 > 위젯 직접등록 | 170×600 (두 배로 찍음) |

메뉴 이름은 네이버가 바꾸면 달라질 수 있다.

네 장 모두 세 배로 크게 그린 뒤 제 크기로 줄였다. 픽셀 수는 규격 그대로이고, 글자 가장자리의 색 번짐과 윤곽의 계단만 없앴다(`render.mjs` 의 `SUPERSAMPLE`).

## 올릴 때 챙길 것

- **프로필**: 모서리를 둥글리지 않았다. 네이버가 원으로 잘라 보여서, 둥근 모서리를 두면 두 번 깎인다.
- **모바일 커버**: 아래 3분의 1쯤은 일부러 비워 두었다. 네이버가 그 자리에 블로그명·별명·이웃추가 단추를 얹는다. 커버 스타일은 글자가 아래에 오는 것을 고른다. 얹힌 글자가 밝은 바탕에서 잘 안 읽히면 어두운 판 커버를 쓴다(글자 색은 올려 보고 확인한다). 폰과 PC는 서로 다른 그림을 보여 주니 섞어 써도 된다.
- **PC 타이틀**: 로고와 슬로건이 그림에 들어 있다. 타이틀 영역 높이를 300으로 맞추고, 블로그 제목 글자 표시는 끈다. 켜 두면 제목이 두 번 나온다.
- **위젯**: 위젯은 파일이 아니라 HTML을 받는다. 비공개 글에 이 그림을 올리고 그림 주소를 복사해 아래 `이미지 주소` 자리에 넣는다. 그림은 두 배 크기라 `width="170"` 을 꼭 준다.

```html
<a href="https://hatzze.fun/?utm_source=naver_blog&utm_medium=widget" target="_blank"><img src="이미지 주소" width="170" height="600" alt="hatzze.fun 열기"></a>
```

`utm_*` 는 GA4가 알아서 읽는다. 블로그 위젯에서 온 방문을 따로 셀 수 있다.

## 소개 글(`intro/`)

블로그 첫 글 '햇쩨를 소개합니다'. 카테고리 '햇쩨 소식'에 공지로 올린다.

| 파일 | 쓰는 곳 |
|---|---|
| `intro/draft.md` | 원고. 스마트에디터에 붙여 넣고 `[소제목]` 줄을 소제목 서식으로 바꾼다 |
| `intro/01-cover-1080.png` | 사진 1 · 대표 이미지(검색 썸네일이 정사각으로 잘려서 정사각) |
| `intro/02-screens-1080.png` | 사진 2 · 사이트 화면 여덟 개. 묶음은 사이드바와 같다 |
| `intro/03·04·05-*.png` | 사진 3·4·5 · 실제 화면(시장 브리핑 · 카더라 · 테마). `capture.mjs` 로 찍은 `intro/shots/` 를 `render.mjs` 가 틀에 넣는다 |
| `intro/06-posts-1080.png` | 사진 6 · 이 블로그에 올라오는 글 넷 |

실제 화면은 폰 폭(390)을 세 배로 찍는다. 폰으로 직접 캡처한 그림을 같은 이름(`briefing.png` · `kadera.png` · `theme.png`)으로 `intro/shots/` 에 두어도 된다.

그림 속 글자는 네이버가 읽지 못하니, 같은 내용을 원고 본문에도 글로 적어 두었다. 화면이 늘거나 이름이 바뀌면 `render.mjs` 의 `introScreens` 와 원고를 같이 고친다.

## 말풍선 넷은 카테고리 넷이다

오늘 뭐래?(데일리 요약) · 요즘 무슨 테마?(테마) · 배당 얼마 받지?(배당) · 고점 대비 몇 %?(MDD).
파란 말풍선은 '오늘 뭐래?' 하나다. 매일 나가는 글이자 텔레그램 채널 이름이라 햇쩨 자신의 말이다.
사라/팔라로 읽힐 말과 종목 이름은 넣지 않는다(`app/og-card.tsx` 의 `ChatterArt` 와 같은 규칙). 커버 뒤의 선도 같은 이유로 방향 없이 오르내리기만 한다.

## 다시 그리기

```bash
npm install
CHROME=<chrome-headless-shell 경로> node docs/naver-blog/render.mjs              # 밝은 판
THEME=dark CHROME=<chrome-headless-shell 경로> node docs/naver-blog/render.mjs   # 어두운 판
```

결과는 같은 폴더에 덮어쓴다. 다른 곳에 받으려면 `OUT_DIR=<폴더>` 를 준다.

일반 크롬이 아니라 **헤드리스 셸**이어야 한다. 일반 크롬의 헤드리스는 창 높이에서 87px을 빼고 그려 아래가 잘린다. 없으면 `npx @puppeteer/browsers install chrome-headless-shell@stable` 로 받는다.
